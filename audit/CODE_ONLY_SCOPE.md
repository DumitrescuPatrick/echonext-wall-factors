# Code-only audit scope

This is a new source-only package assembled from the previously audited integrated repository. Original analytical Python modules and configuration files were copied without changing their scientific implementation; their hashes are recorded. No data directories or prior aggregate/publication files were copied. No source archives, compiled caches, models, patient manifests, personal download origins or credentials are included.

The original tests use synthetic arrays and artificial metadata rows. A source/schema name such as subject_id, a method threshold, a random seed or a configuration's design description is not an individual identifier value. Historical report-generator modules are Python source only; their saved research outputs and private prerequisites are not distributed.

Checks cover the allowlisted file set, hashes, forbidden formats/locations, AST syntax and explicit identifier/credential/path patterns. These checks do not constitute provider or institutional legal approval, clinical validity or an audit of an existing online repository history. Any future clinical data added to a repository falls outside this release audit.
